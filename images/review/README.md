## hide.svg / show.svg  ← 덮어쓰면 됩니다

`login.html` 비밀번호 칸 오른쪽의 보기 토글 아이콘입니다.
지금 들어있는 건 임시로 그린 것이니 **같은 파일명으로 덮어쓰세요.**
코드 수정은 필요 없습니다.

| 파일 | 언제 보이나 | 모양 |
|---|---|---|
| `hide.svg` | 비밀번호가 **가려져 있을 때** (첫 화면) | 눈 + 사선 |
| `show.svg` | 비밀번호가 **보일 때** (토글한 뒤) | 사선 없는 눈 |

이름은 '지금 비밀번호가 어떤 상태인지'를 가리킵니다. 누르면 하는 '동작'이 아닙니다.
반대 규칙이면 `login.html` 의 `.lg-eye[aria-pressed="true"] i` 규칙에서
두 파일 이름만 바꾸면 됩니다.

### 색은 파일이 아니라 CSS 가 정합니다

CSS `mask` 로 실루엣만 떠서 색을 입히는 구조입니다. 그래서
**파일 안의 색은 무시됩니다** — 모양만 맞으면 됩니다.

색은 `--ds-text-disabled` (= `#8A949E`, 피그마 `Color/Icon/gray-light`) 이고,
`login.html` 의 `:root` 에 있습니다. 김반장 3.0 디자인 시스템 토큰이라
`index.html` 의 같은 이름 토큰과 값이 같습니다.

- 규격 : 20 × 20 으로 그려집니다 (`viewBox`는 자유, 정사각형이면 됩니다)
- 모양은 단색 실루엣이어야 합니다. 여러 색이 섞여 있어도 알파만 쓰이므로
  전부 같은 색으로 나옵니다
- 피그마 위치 : `/login` → `3597:21126` → `Text input_atomic` → `icon_size` → `icon`

> 참고 : `mask` 는 `file://` 로 파일을 직접 열면 브라우저가 막아서 아이콘이
> 안 보입니다. GitHub Pages 같은 http(s) 에서는 정상입니다. 로컬에서 확인하실 땐
> 폴더에서 `python3 -m http.server` 로 띄워 보세요.
