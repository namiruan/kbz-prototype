# 소개페이지 사진 — 지금은 스켈레톤

`card-reader.html`(퇴직공제 전자카드 단말기)과 `face-attendance.html`(안면인식
출퇴근관리 단말기)의 **사진 자리는 모두 비어 있습니다.** 제품컷을 새로 찍는
동안 자리만 잡아 두었고, 화면에는 점선 상자에 「무엇이 들어갈지 · 어떤
파일이어야 하는지」가 적혀 있습니다.

처음 만들 때 라이브(kbz.co.kr)의 다른 소개페이지에서 빌려 끼워 둔 그림들은
지웠습니다. 되살릴 일이 있으면 커밋 `d27dba2` 이전을 보세요.

## 사진이 나오면

`<span class="ph">…</span>` 를 `<img>` 로 바꾸기만 하면 됩니다. 자리 크기는
스켈레톤과 같으니 레이아웃은 그대로입니다.

```html
<!-- 지금 -->
<span class="ph ph-sm"><b class="ph-cap">벽부형 제품컷</b><i class="ph-spec">투명 PNG · 348×332</i></span>
<!-- 사진이 나오면 -->
<img src="images/intro/device/wall.png" alt="벽부형 퇴직공제 전자카드 단말기" loading="lazy">
```

## 사진 찍을 때

- **배경이 투명한 PNG.** 사진 뒤에 배경색을 깔지 않습니다. 흰 사각형 배경이
  있으면 짙은 파랑 바탕(`partition-5`)과 옅은 파랑 바탕(`img-group2`) 위에서
  테가 보입니다.
- **바닥 맞춤.** 단말기가 프레임 아래쪽에 닿아야 '잘린' 게 아니라 '놓여
  있는' 것으로 읽힙니다. `partition-5` 의 합성 컷은 키가 달라도 **바닥선을
  맞춰** 나란히 놓습니다.
- **좌우 여백**을 조금 두세요. 폭에 맞춰 줄어듭니다.
- **전자카드 제품컷 세 장은 작게 들어갑니다** — `partition-3` 의 자리가
  174×166(2배로 348×332)입니다. 큼직한 제품컷은 `partition-5` 의 3종 한 컷
  하나뿐이니, 거기에 힘을 주세요.
- **배경 두 자리**는 글이 위에 얹히니 가운데 위쪽을 비워 두고 찍습니다.

## 뺀 것

- **고객사 로고 띠**와 **후기 카드**는 구역에서 들어냈습니다. 두 제품으로 남은
  후기가 아직 없어서입니다. 되살릴 때는 `.partition-4` 에서 `is-proof` 를 떼고
  라이브 틀의 `slide-wrapper` · `panel-group-arr` 을 되돌립니다 — `.slide-*` 와
  `.panel-*` CSS 는 그대로 두었습니다.
- **롤링 띠 아이콘**(`marquee-icon.png`)도 지웠습니다. 안면인식 쪽 띠는 이제
  점(CSS `.rolling-txt::after`)으로 문구를 끊습니다.

지금 두 페이지에는 `<img>` 가 하나도 없습니다. 사진 자리는 모두 위 표의
스켈레톤입니다.
