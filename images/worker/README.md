# 근로자 얼굴 사진 — 지금은 비어 있습니다

안면 출퇴근 앱 화면(`face-attendance-app.html`)의 얼굴 자리는 **아직 사진이
없습니다.** 갈색 그라데이션에 사람 아이콘이 얹힌 것이 그 자리표시입니다.

사진은 저장소 밖에서 가져오지 않습니다 — 소개페이지에서 라이브 사진을 빌려
썼다가 다 걷어 낸 것과 같은 까닭입니다(`images/intro/README.md`).

## 넣을 파일

| 파일 | 누구 | 화면에서 쓰는 곳 |
| --- | --- | --- |
| `01.jpg` | 홍길동 (형틀목공) | 목록 썸네일 · 근로자 상세 · 이력 사진 · 촬영 확인 |
| `02.jpg` | 김철수 (철근공) | 목록 썸네일 |
| `03.jpg` | 이영희 (보통인부) | 목록 썸네일 |
| `04.jpg` | 박민수 (형틀목공) | 목록 썸네일 |

**NGUYEN VAN A 는 넣지 않습니다.** 얼굴을 등록하지 않은 근로자라, 빈 자리가
그대로 있는 것이 이 목록에서 갈리는 값입니다.

## 규격

| | |
| --- | --- |
| 크기 | **600×600 이상, 정사각** — 한 장을 네 자리에서 돌려 쓰므로 가장 큰 자리(이력 사진 420×400)보다 커야 합니다 |
| 자르기 | 얼굴이 **가운데**. 자리마다 비율이 달라 `object-fit:cover` 로 가장자리를 잘라 씁니다 |
| 형식 | JPG · 한 장 200KB 아래 |
| 담긴 것 | 안전모를 쓴 현장 근로자의 상반신. 출퇴근 인증 사진이라 **정면·눈이 보이는 것** |

## 사진이 오면

`<span class="face">` 안의 `<svg>` 를 `<img>` 로 바꾸기만 하면 됩니다. 자리
크기와 모서리는 `.face` 가 이미 잡고 있어 레이아웃은 그대로입니다.

```html
<!-- 지금 -->
<span class="face"><svg class="ic" aria-hidden="true"><use href="#icon-employee"></use></svg></span>
<!-- 사진이 오면 -->
<span class="face"><img src="images/worker/01.jpg" alt=""></span>
```

`alt` 는 비웁니다 — 바로 옆에 이름이 적혀 있어 읽어 주면 같은 말이 두 번
들립니다.

## 실제 사람의 얼굴을 쓸 때

이 화면은 **얼굴로 출퇴근을 찍는 제품**의 화면입니다. 실존 인물의 사진을
가짜 이름·가짜 주민번호 옆에 두면 그 사람이 이 현장에서 일하는 것처럼
읽힙니다. 모델 동의를 받은 사진이나 생성한 얼굴을 쓰고, 어느 쪽인지 이
파일에 적어 둡니다.
