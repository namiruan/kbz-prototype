# 근로자 얼굴 사진

안면 출퇴근 앱 화면(`face-attendance-app.html`)이 쓰는 얼굴입니다.

| 파일 | 누구 | 화면에서 쓰는 곳 |
| --- | --- | --- |
| `01.jpg` | 홍길동 (800101-1, 형틀목공) | 목록 썸네일 · 근로자 상세 · 이력 사진 · 촬영 확인 |
| `02.jpg` | 김철수 (750512-1, 철근공) | 목록 썸네일 |
| `03.jpg` | 이영희 (880303-2, 보통인부) | 목록 썸네일 |
| `04.jpg` | 박민수 (920715-1, 형틀목공) | 목록 썸네일 |

**NGUYEN VAN A 는 사진이 없습니다.** 얼굴을 등록하지 않은 근로자라, 빈 자리가
그대로 있는 것이 이 목록에서 갈리는 값입니다 — 채우면 그 차이가 사라집니다.

**얼굴은 주민번호와 맞춰 골랐습니다.** 1975년생 옆에 서른 살 얼굴이 있으면
화면을 읽는 사람이 둘 중 무엇이 거짓인지 먼저 따지게 됩니다. 이영희는 뒷자리
2 라 여성 사진입니다.

## 규격

| | |
| --- | --- |
| 크기 | **600×600 정사각** — 한 장을 네 자리에서 돌려 씁니다. 가장 큰 자리가 이력 사진(최대 420×400)이라 이만하면 넉넉합니다 |
| 형식 | JPG · progressive · 품질 82 · 한 장 50KB 안팎 |
| 자르기 | 얼굴이 가운데. 자리마다 비율이 달라 `object-fit:cover` 로 가장자리를 잘라 씁니다 |

받은 원본은 2000×2000 이었고 위 규격으로 줄여 넣었습니다. 더 큰 자리가
생기면 원본에서 다시 뽑는 편이 낫습니다.

## 바꿀 때

`<span class="face">` 안의 `<img>` 주소만 갈면 됩니다. 크기와 자르기는 CSS 가
잡고 있어 레이아웃은 그대로입니다.

```html
<span class="face"><img src="images/worker/01.jpg" alt=""></span>
```

`alt` 는 비웁니다 — 바로 옆에 이름이 적혀 있어 읽어 주면 같은 말이 두 번
들립니다.

## ⚠ 출처

이 화면은 **얼굴로 출퇴근을 찍는 제품**의 화면입니다. 실존 인물의 사진을
가짜 이름·가짜 주민번호 옆에 두면 그 사람이 이 현장에서 일하는 것처럼
읽힙니다.

지금 사진은 기획자가 넘긴 것입니다. **실존 인물인지 생성한 얼굴인지 여기에
적어 두세요** — 실존 인물이면 모델 동의가 있어야 하고, 동의 범위를 넘는
자리(소개페이지 따위)에 옮겨 쓰지 않아야 합니다.
