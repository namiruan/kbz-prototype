# 안면인식 단말기 사진

`face-quote.html`의 **단말기 수량** 카드에 들어가는 사진입니다.
**같은 파일명으로 덮어쓰면** 바로 반영됩니다.

| 파일 | 단말기 |
| --- | --- |
| `ubio-x-face-pro.png` | Ubio X Face Pro |

현재 파일은 메인 페이지의 `images/device/A-01.png`를 복사해 자리를 잡아둔 것입니다.
제품컷이 따로 있으면 덮어써 주세요.

## 권장 사양

- **크기** 800 × 600 (4:3) 권장. 비율은 자유이며 잘리지 않고 통째로 들어갑니다.
- **형식** 배경이 투명한 PNG. 사진 뒤에 배경색을 깔지 않으므로 카드 배경(흰색) 위에
  그대로 얹힙니다. 흰 사각형 배경이 있으면 카드와 경계가 보입니다.
- **정렬** 사진은 아래 끝에 맞춰 표시됩니다. 단말기가 프레임 아래쪽에 닿도록
  잡아주시면 '잘린' 게 아니라 '놓여 있는' 것으로 읽힙니다.
- **좌우 여백** 폭에 맞춰 줄어드니 좌우에는 약간 여백을 두세요.

파일명을 바꾸려면 `face-quote.html`의 `.dev-media img`에 있는 `src`도 함께 고쳐야 합니다.
