# 단말기 선택 카드 사진

`quote.html`의 **03 단말기 선택** 카드에 들어가는 사진입니다.
현재 파일은 자리를 잡아두기 위한 placeholder이므로 **같은 파일명으로 덮어쓰면** 바로 반영됩니다.

| 파일 | 단말기 |
| --- | --- |
| `wall.png` | 벽부형 |
| `mobile.png` | 이동형 |
| `portable.png` | 휴대형 |

## 권장 사양

- **크기** 800 × 600 (4:3). 카드가 좁아도 `object-fit: contain`으로 비율을 지켜 줄이므로 더 커도 됩니다.
- **형식** 배경이 투명한 PNG. 카드를 선택하면 배경이 옅은 파랑으로 바뀌는데, 투명이어야 그 색이 사진 뒤로 비칩니다.
- **여백** 단말기가 프레임에 꽉 차지 않도록 사방에 약간 여백을 두세요. 오른쪽 위에 선택 체크 표시가 얹힙니다.
- **구도** 3장의 촬영 각도와 크기를 맞추면 카드가 나란히 놓였을 때 정돈돼 보입니다.

파일명을 바꾸려면 `quote.html`의 `.dev-media img` 세 곳에 있는 `src`도 함께 고쳐야 합니다.
