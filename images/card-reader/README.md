# 단말기 선택 카드 사진

`quote.html`의 **03 단말기 선택** 카드에 들어가는 사진입니다.
현재 파일은 자리를 잡아두기 위한 placeholder이므로 **같은 파일명으로 덮어쓰면** 바로 반영됩니다.

| 파일 | 단말기 |
| --- | --- |
| `wall.png` | 벽부형 |
| `mobile.png` | 이동형 |
| `portable.png` | 휴대형 |

## 권장 사양

- **크기** 800 × 600 (4:3) 권장. 비율은 자유이며 잘리지 않고 통째로 들어갑니다.
- **형식** 배경이 투명한 PNG. 카드 안 사진 띠가 옅은 회색이라 투명이어야 자연스럽게 얹힙니다.
- **정렬** 사진은 띠의 **아래 끝에 맞춰** 표시됩니다. 제품컷은 흔히 아래가 잘린 채로 오는데,
  바닥에 붙으면 '잘린' 게 아니라 '놓여 있는' 것으로 읽힙니다. 단말기가 프레임 아래쪽에 닿도록
  잡아주시면 가장 자연스럽습니다.
- **좌우 여백** 띠 폭에 맞춰 줄어드니 좌우에는 약간 여백을 두세요.
- **오른쪽 아래 모서리** 단말기를 고르면 수량 조절 버튼이 사진 위 오른쪽 아래에 뜹니다.
  흰 배경에 그림자가 있어 어떤 사진 위에서도 읽히지만, 그 자리에 단말기가 걸치지 않도록
  가운데나 약간 왼쪽으로 두면 더 깔끔합니다.
- **구도** 3장의 촬영 각도와 크기를 맞추면 카드가 나란히 놓였을 때 정돈돼 보입니다.

파일명을 바꾸려면 `quote.html`의 `.dev-media img` 세 곳에 있는 `src`도 함께 고쳐야 합니다.
