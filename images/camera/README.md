# 카메라가 비추는 화면

안면 출퇴근 앱의 **카메라 인식**·**인식 결과** 화면(`face-attendance-app.html`
의 `m-cam` · `m-cam-ok`)에서 바탕으로 까는 사진입니다. 앱(Flutter)이 붙으면
그 자리에 실시간 미리보기가 옵니다 — 그때까지 **무엇을 맞추라는 것인지**를
그림으로 말해 두는 자리입니다.

| 파일 | 쓰는 곳 |
| --- | --- |
| `preview.jpg` | 카메라 인식 · 인식 결과의 바탕 |

회색 그라데이션으로 두었을 때는 카메라가 꺼진 화면처럼 보였고, 가이드
사각형이 무엇을 담으라는 틀인지도 드러나지 않았습니다.

## 규격

| | |
| --- | --- |
| 크기 | **1036 × 2000 세로** — 폰 화면과 비율이 거의 같아, 390 폭에서는 세로가 딱 맞아떨어져 자르는 데가 없습니다 |
| 형식 | JPG · progressive · 품질 72 · 163KB |
| 자르기 | `background-size:cover` · 세로 기준점 13%. 기준점은 **태블릿의 몫**입니다 — 폰에서는 자를 것이 없어 아무 일도 하지 않지만, 칸이 넓어지면 위아래가 잘리면서 얼굴이 가이드 사각형 위로 올라가 머리말과 겹칩니다 |
| 얼굴 자리 | 가이드 사각형은 칸의 **24~66%** 입니다. 얼굴이 그 안에 들어야 합니다 — 사진을 갈 때 먼저 볼 것이 이것입니다 |

## 바꿀 때

`assets/face-attendance-app.css` 의 `.cam` 에 주소가 있습니다. 같은 파일명으로
덮어쓰면 바로 반영됩니다. 비율이 많이 다른 사진으로 갈면 세로 기준점(13%)도
다시 잡아야 합니다.
